# Financy

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Confirmada pelo usuário: React, Vite, TypeScript, Tailwind CSS v4, TanStack Query, React Hook Form, Zod; Node.js, Apollo Server, TypeGraphQL, Prisma e PostgreSQL.

## Users

Pessoas organizando suas finanças pessoais por transações e categorias.

## Product Purpose

Entrega de pós-graduação: aplicação fullstack com cadastro, login e gerenciamento dos dados exclusivos de cada usuário.

## Capabilities and Constraints

CRUD de transações e categorias; autenticação JWT; GraphQL obrigatório no front e no back; execução local; pastas backend e frontend; exemplos de ambiente. Interface responsiva para web e celular. Extras ficam separados da entrega obrigatória.

## Brand Commitments

Nome Financy; reproduzir o Figma fornecido, incluindo seu Style Guide. Idioma português brasileiro, valores em BRL.

## Evidence on Hand

Enunciado fornecido em Texto colado.txt e Figma https://www.figma.com/design/0RzI8OQnhElvnyGAygeYmE/Financy--Community- . Não há dados reais ou autorização para inventar métricas.

## Product Principles

- Proteger o isolamento de dados na API.
- Representar dinheiro em centavos inteiros.
- Tornar erros e resultados das operações claros.
- Preservar a entrega acadêmica antes dos extras.

## Hospedagem

PostgreSQL no Neon e frontend/API no Render autorizados pelo usuário. PostgreSQL é uma alternativa permitida pelo enunciado. O ambiente local usa PostgreSQL no Docker, sem depender do Neon.
